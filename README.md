# Catering by Chef Pérez

Sitio web oficial de Catering by Chef Pérez, una propuesta de catering,
pasteles personalizados y repostería artesanal para eventos sociales y
corporativos en Ciudad de México.

## Páginas

- Inicio con servicios, proceso, galería y preguntas frecuentes
- Perfil de la chef Valeria Pérez y su trayectoria
- Páginas independientes para catering, pasteles y repostería
- Contacto y cotización directa por WhatsApp

## Tecnología

- Next.js 16 y React 19
- TypeScript
- Vinext para despliegue compatible con Cloudflare Workers
- CSS responsivo sin framework visual

## Desarrollo local

```bash
npm install
npm run dev
```

La aplicación estará disponible en la dirección local indicada por la terminal.

## Verificación

```bash
npm run build
npm test
```
